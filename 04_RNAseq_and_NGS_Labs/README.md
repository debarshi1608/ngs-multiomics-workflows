# Advanced NGS & Transcriptomic Workflows

## Overview
Collection of specialized high-throughput sequencing analyses, including single-cell transcriptomics, bisulfite sequencing, and variant discovery.

## Modules Covered
1. **Single-Cell RNA-Seq (scRNA-seq):** Quality control, clustering, and marker gene identification using `Seurat`.
2. **Bisulfite-Seq (Bismark):** Methylation calling and CpG context analysis.
3. **Variant Calling Pipeline:** SNP/Indel identification, filtering, and annotation workflows.
4. **General RNA-Seq Workflows:** Differential gene expression and exploratory data analysis.

# Functional Genomics & Pathway Enrichment

## Overview
Functional annotation and systems-level interpretation of candidate gene lists derived from high-throughput screens.

## Methods
* **Gene Ontology (GO) Enrichment:** Evaluated biological processes, molecular functions, and cellular component over-representation.
* **Pathway Mapping:** Mapped core targets onto metabolic and signaling pathways (KEGG / Reactome) to identify perturbed biological networks.
